About WordCount Pro

From a student-era monolith to an enterprise-grade text analytics and readability engine built with Keystone Clean Architecture principles.

🏛️ Architectural Pillars (Keystone Clean Architecture)

Pure Domain Layer

Linguistic tokenization, syllable heuristics, and Flesch readability formulas built with pure Python. Zero external runtime dependencies.

Application Use Cases

Strongly-typed DTOs, strict input boundaries (DoS mitigation), and execution performance telemetry.

Hexagonal Adapters

Ports and Adapters decouple delivery: identical domain logic powers both the async FastAPI Web API and the terminal CLI tool.

Production Hardening

Twelve-Factor settings, structured logging, multi-stage non-root Docker security, and automated multi-version CI pipelines.

📊 Computed Metrics

  • Words, Unique Vocabulary & Density: Unicode-aware tokenization handling contractions and multilingual text (including Turkish characters).
  • Readability Scores: Flesch Reading Ease Index & Flesch-Kincaid Grade Level complexity categorization.
  • Reading & Speaking Times: Standardized 225 WPM silent reading and 135 WPM presentation speech rate models.
  • Keyword Density Analysis: Relative frequency distribution with optional English and Turkish stopword suppression.

🛠️ Technology Stack

Python 3.11+ FastAPI Starlette Pydantic Jinja2 Vanilla JS (Reactive) Docker (Non-Root) GitHub Actions CI Pytest / Unittest Ruff & MyPy
